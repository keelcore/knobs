## Becoming a Maintainer

1. **Consistent contribution** — merged pull requests across languages and areas, including tests and documentation.
2. **Code review** — constructive reviews of other contributors' pull requests.
3. **Community engagement** — triaging issues and answering questions.
4. **Nomination** — an existing maintainer nominates the contributor with a pull request to this file; the
   maintainers approve by simple majority.

## Maintainer Responsibilities

- Review and merge (or close) pull requests in a timely manner.
- Triage new issues within 5 business days.
- Cut releases following [release-policy.md](release-policy.md).
- Enforce the [Code of Conduct](CODE_OF_CONDUCT.md).
